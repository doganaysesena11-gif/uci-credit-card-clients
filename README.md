# Credit Card Default Prediction (Logistic Regression)

## Project Purpose
This project was created as a beginner-level machine learning exercise while learning Logistic Regression.

## Dataset
UCI Credit Card Default dataset is used.

## Steps Performed
- Data loading and basic preprocessing
- Train-test split
- Logistic Regression model training
- Basic prediction and accuracy evaluation

## Notes
This project focuses on understanding the basic workflow of a classification model.
Further improvements such as feature scaling and advanced evaluation metrics are planned.
